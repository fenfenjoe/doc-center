# SubAgent

## 概述

SubAgent（子代理）是一种将复杂任务分解给多个专门化 AI 代理协作完成的架构模式。每个 SubAgent 负责特定领域的工作，类似于团队中不同角色的成员。

**核心理念：**
- 专业化分工：每个 Agent 专注于特定任务
- 协作完成：Agent 之间可以相互调用
- 降低复杂度：大任务拆解为小任务
- 提高准确性：专门化提升质量

## SubAgent 架构模式

```
┌─────────────────┐
│  Master Agent   │ (主协调者)
└────────┬────────┘
         │
    ┌────┼────┬────────┐
    │    │    │        │
┌───▼──┐ │ ┌──▼───┐ ┌─▼────┐
│Code  │ │ │Test  │ │Doc   │
│Agent │ │ │Agent │ │Agent │
└──────┘ │ └──────┘ └──────┘
         │
    ┌────▼────┐
    │Review   │
    │Agent    │
    └─────────┘
```
