# 自动化迭代

## 如何通过AI让项目自动化迭代

### 核心思路

将项目迭代流程转化为可被 AI 理解和执行的自动化工作流，通过 Skills、MCP 和 SubAgent 的组合实现持续演进。

### 自动化迭代架构

```
┌──────────────────────────────────────────┐
│         需求分析 (Requirement Agent)      │
│  - 理解用户需求                           │
│  - 生成技术方案                           │
│  - 拆解任务清单                           │
└───────────────┬──────────────────────────┘
                │
┌───────────────▼──────────────────────────┐
│         开发执行 (Dev Agent Team)         │
│  ┌────────┐ ┌────────┐ ┌──────────┐     │
│  │ Code   │ │ Test   │ │ Doc      │     │
│  │ Agent  │ │ Agent  │ │ Agent    │     │
│  └────────┘ └────────┘ └──────────┘     │
└───────────────┬──────────────────────────┘
                │
┌───────────────▼──────────────────────────┐
│         质量检查 (QA Agent)               │
│  - 代码审查                               │
│  - 测试执行                               │
│  - 性能检测                               │
└───────────────┬──────────────────────────┘
                │
┌───────────────▼──────────────────────────┐
│         部署发布 (Deploy Agent)           │
│  - 构建打包                               │
│  - 自动部署                               │
│  - 版本管理                               │
└───────────────┬──────────────────────────┘
                │
┌───────────────▼──────────────────────────┐
│         监控反馈 (Monitor Agent)          │
│  - 收集反馈                               │
│  - 生成改进建议                           │
│  - 触发新迭代 ──────────┐                │
└─────────────────────────┼────────────────┘
                          │
                          └─► (循环迭代)
```

### 关键成功要素

1. **明确的反馈循环**：每次迭代都要收集数据并生成下一步行动
2. **质量门禁**：设置自动检查点，不合格不允许发布
3. **版本管理**：每次迭代生成清晰的版本记录
4. **监控告警**：及时发现问题并自动触发修复
5. **人工介入点**：关键决策仍需人工确认
