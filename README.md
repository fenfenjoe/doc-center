# 说明

本项目为个人知识库，用于记录和管理项目文档、SKILLS、开发笔记等内容。

## 项目结构

```
doc-center/
├── Doc/              # 开发笔记和技术文档
├── Projects/         # 项目需求文档、设计文档
├── Skills/           # 个人开发或收录的 Skill 集合
└── README.md         # 项目说明文档
```

## 如何使用本项目

1. 下载&安装Trae

略

2. 安装node.js和npm

略

```bash
node -v
npx -v
```

3. 安装 find-skills 技能

```bash
npx skills add https://github.com/vercel-labs/skills --skill find-skills
```
