# anime-lyrics-publisher - 需求分析文档

## 项目背景

本项目是一个自动化动漫歌词爬取与发布系统，旨在为微信公众号提供持续的日语学习内容。系统通过爬取动漫歌曲歌词，利用AI分析生成带翻译和语法解析的学习文章，并自动发布到微信公众号。

## 技术栈概述

- **编程语言**: Python
- **框架**: APScheduler (定时任务调度)
- **数据库**: SQLite
- **构建工具**: pip

## 功能需求

### 核心功能

#### 1. 歌词爬取

- **QQ音乐爬虫**: 通过QQ音乐API搜索并获取动漫歌曲歌词
- **精确匹配**: 支持按动画名、歌曲名、歌手精确匹配
- **歌曲类型**: 支持OP(片头曲)、ED(片尾曲)、IN(插曲)、TM(主题曲)
- **动画池管理**: 主动画池+后备动画池，自动补充新动画

#### 2. AI歌词分析

- **翻译生成**: 将日语歌词翻译为中文
- **语法解析**: 分析歌词中的语法点和词汇用法
- **语言检测**: 自动检测歌词语言（日语/英语/韩语/中文）
- **文章格式化**: 将分析结果格式化为微信公众号文章格式

#### 3. 微信公众号发布

- **素材上传**: 支持上传图片素材到微信
- **草稿创建**: 创建图文消息到微信草稿箱
- **文章发布**: 自动发布文章到微信公众号
- **封面管理**: 支持自定义封面和默认封面生成

#### 4. 图片爬取

- **MyAnimeList API**: 从MAL API获取动画官方图片
- **感知哈希去重**: 使用aHash算法检测视觉重复图片
- **本地缓存**: 图片缓存系统，支持未使用图片优先、自动补仓、回退复用
- **封面生成**: 自动生成默认封面图

### 辅助功能

#### 1. 定时任务调度

- **每周爬取**: 每周六凌晨2:00自动执行歌词爬取
- **每日发布**: 每天早上7:00自动发布文章
- **手动触发**: 支持手动执行各任务

#### 2. 数据库管理

- **动画管理**: 添加、查询、更新动画状态
- **歌词管理**: 存储歌词数据，支持随机获取未使用歌词
- **文章管理**: 记录文章状态和微信素材ID
- **任务日志**: 记录任务执行状态和结果

#### 3. 系统状态查看

- **数据库状态**: 显示动画总数、待爬取/已完成数量
- **最近任务**: 显示最近5条任务执行记录
- **最近文章**: 显示最近5篇文章状态

## 非功能需求

### 性能要求

- **爬取速度**: 单次爬取任务应在5分钟内完成
- **文章生成**: 文章生成+AI分析应在3分钟内完成
- **图片处理**: 图片下载+去重应在30秒内完成

### 安全要求

- **API密钥保护**: 微信AppID/AppSecret不应硬编码（当前版本存在此问题）
- **Token管理**: access_token应自动刷新，避免过期

### 可用性要求

- **容错处理**: 爬取失败时应记录日志并继续处理其他动画
- **重试机制**: 网络请求失败应支持重试

## 接口需求

### 外部接口

#### 1. QQ音乐API

- **搜索接口**: 搜索动漫歌曲
- **歌词接口**: 获取歌词内容

#### 2. MyAnimeList Jikan API

- **动画搜索**: 根据动画名搜索
- **图片获取**: 获取动画封面和剧照

#### 3. 微信公众号API

- **Token获取**: 获取access_token
- **素材上传**: 上传图片素材
- **草稿创建**: 创建图文消息
- **文章发布**: 发布文章

#### 4. LLM API

- **歌词分析**: 调用OpenAI/Anthropic/WorkBuddy API分析歌词

### 内部接口

#### 1. 数据库接口

- `Database.add_anime()`: 添加动画
- `Database.get_random_pending_anime()`: 获取随机待爬取动画
- `Database.add_lyrics()`: 添加歌词
- `Database.get_random_unused_lyrics()`: 获取随机未使用歌词
- `Database.add_article()`: 添加文章
- `Database.update_article_wechat_ids()`: 更新文章微信ID

## 数据需求

### 数据存储

- **SQLite数据库**: `data/anime_lyrics.db`
- **图片缓存**: `data/anime_images/{anime_name}/`
- **AI交换文件**: `data/pending_analysis.json`, `data/analysis_result.json`

### 数据流

```
动画池 → QQ音乐爬虫 → 歌词数据 → 数据库
数据库歌词 → AI分析 → 分析结果 → 文章生成 → 微信公众号
```

## 约束条件

### 技术约束

- **Python版本**: 需要Python 3.8+
- **依赖库**: requests, BeautifulSoup4, PIL/Pillow, APScheduler
- **数据库**: SQLite（单文件数据库，适合小型项目）

### 业务约束

- **歌词版权**: 歌词内容涉及版权问题，需注意合规性
- **微信限制**: 微信公众号API有调用频率限制
- **AI成本**: LLM调用可能产生费用
