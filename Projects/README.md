## 初始化项目文档

用以下提示词，可以：
- 根据GIT地址将项目拉取到本地（若本地不存在则创建）
- 分析项目代码结构
- 在Projects目录下创建项目文档目录

```
用户: 初始化{xxx}项目文档，GIT地址是https://github.com/xxx.git，本地路径是C:/Users/Admin/Desktop/xxx/
```
